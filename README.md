### 01. Python for AI Engineering
- Python fundamentals and syntax
- Variables, data types, and type casting
- Strings and collection data structures
- Conditional statements and loops
- Functions, recursion, and lambda expressions
- Exception handling and file operations
- Object-Oriented Programming
- NumPy and matrix operations
- Pandas and data manipulation
- Matplotlib, Seaborn, and Plotly
- Streamlit fundamentals

### 02. Mathematics for AI/ML
- Linear Algebra
- Vectors and Matrices
- Probability and Probability Distributions
- Statistics and Hypothesis Testing
- Calculus and Partial Derivatives
- Gradients and the Chain Rule
- Optimization and Gradient Descent

### 03. Machine Learning & Feature Engineering
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature engineering
- Handling missing values and outliers
- Feature scaling and categorical encoding
- Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Trees and Random Forests
- Support Vector Machines (SVM)
- Model evaluation and performance metrics

### 04. Deep Learning
- Perceptrons and Neural Networks
- Multi-Layer Perceptrons (MLP)
- Artificial Neural Networks (ANN)
- Forward and Backpropagation
- Activation and Loss Functions
- Optimization Algorithms
- Regularization and Dropout
- Batch Normalization
- PyTorch Fundamentals

### 05. Advanced Deep Learning & NLP
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN)
- Sequence Modeling
- Text Preprocessing and Tokenization
- Text Representation
- Word Embeddings and Word2Vec
